# Cloudscape

A responsive, static cloud-operations dashboard for the Group 10 web app project.

## Run locally

Open `index.html` in a modern browser. No build step, server, or package installation is required.

## Features

- Responsive overview with cloud usage, infrastructure health, projects, and recent activity.
- Switchable seven-, 30-, and 90-day resource charts.
- Create projects and simulate deployments without a backend.
- Keyboard-accessible project dialog, notifications, and responsive navigation.

The interface uses plain HTML, CSS, and JavaScript. Google Fonts are optional; system fonts are used if they are unavailable.
